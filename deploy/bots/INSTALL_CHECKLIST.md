## Manual steps

1. Open each Bot in grok.com.
2. Paste the matching file from deploy/bots/instructions.
3. Save.
4. Send one task that includes the ResearchInput values, not only an evidence id.
5. Confirm the reply cites a supplied field or says UNAVAILABLE for a missing field.

Do not mark a row installed because the file exists.
